# Meterless analysis compatibility repair

Verified locally on 2026-10-24. Existing snapshots, source metadata, model,
messages, source excerpts, max_tokens (4096), timeout (180 seconds), hidden
token entry and quote validation are preserved. No dependencies were installed.

The analyzer now requests:

- A single Meterless phase (`meterless-tier-split: off`).
- A direct NVIDIA answer (`chat_template_kwargs.enable_thinking: false`).
- JSON output (`response_format.type: json_object`).

The empty tools field remains omitted. There are no client retries. Normal use:

```powershell
python .\scripts\analyze_sources.py
```

NVIDIA's [Lightning guide](https://docs.nvidia.com/nim/large-language-models/2.0.10/get-started/advanced/get-started-nemotron-3.5-lightning.html)
recommends JSON mode for structured output. JSON mode does not replace schema,
source ID, criterion or exact-quote validation.

The installed runtime source was inspected read-only, without accessing stored
credentials. Its proxy supports the tier-split header. The orchestrator can
prepend phase-specific instructions and forwards caller generation options only
to the final phase. This makes a single-phase request appropriate for this
structured extraction task; it does not prove every earlier 502 had one cause.
