# Guided Nextwise hackathon demo

This public-only path was prepared on **27 October 2026**. It is labelled
**Guided demo — pre-verified opportunities**. Verification means the products and
advertised capabilities were confirmed on official public pages. It does **not**
mean verified output quality, safety, suitability, commercial rights or integration.
No product account, generation request, subscription or trial was used.

## Presenter flow

1. Open the public demo with a clean browser state, or use the existing **Clear
   this browser's demo choices** control if products were previously dismissed.
2. Enter the public project description:

   > AI Raw Gourmet is an application that generates and adapts recipes and meal
   > plans to user constraints.

   Additional genuine project details can be included. The recognizer requires
   the project name and the supported recipe/meal-plan personalization goal.
   Name-only, negated identity or unsupported goals do not activate this path.
3. Click **Review project**, then **Find opportunities for my project**.
4. Show exactly two prepared products, their sources and suggested next steps.
   Open **Explain why** to show the limits of the source checks.
5. Click **Explore this**. The visible confirmation states the chosen next step,
   browser-only storage, and that no trial or purchase has begun.
6. Reload and enter/review the same project again: the choice is restored without
   storing the project description. Existing dismissals still apply; the demo
   does not override visitor preferences just to force two cards.

Guided mode makes no discovery request and adds no artificial delay. The decorative
Fibonacci identity forms a large, slowly rotating green-and-gold background behind
the recommendation content, with twinkling stars travelling along its curve.
It remains visible at idle. Its stars become more active
only while real work runs, such as file extraction, local preparation or source
requests. It never changes the prepared-results label to imply live AI discovery.
Reduced-motion preferences disable both idle and processing animations.
The background ignores pointer events; the content and controls remain above it.
Chrome verification includes frames three seconds apart, actual curve travel and
rotation, reduced-motion checks, mobile overflow and button hit testing.
Other businesses retain the current rule-based, bounded GitHub search and honest
one/zero-result handling. No AI reasoning, whole-web search or universal relevance
is claimed. Tavily, private services and paid providers remain disconnected.
